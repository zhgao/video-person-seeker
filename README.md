# 监控视频找人 v1.0

扫描一段**录好的**监控视频，自动找出“有人出现”的时间段，
生成一个可点击跳转的网页报告：点任意片段，视频直接跳到那一刻播放。

## 快速开始

环境要求：Python 3.9+（Windows / macOS / Linux 都可以）

```bash
pip install -r requirements.txt
python detect_people.py 监控录像.mp4
```

> 注意：`pip install` 会下载 PyTorch，体积较大（CPU 版约 200MB；
> Windows/macOS 默认装的 CUDA 版约 2GB），请保持网络畅通，装一次即可。

跑完后打开输出目录里的 **`report.html`**（双击用浏览器打开即可，
不需要联网），点击任意“有人片段”就会跳转播放。

## 常用参数

```bash
python detect_people.py 监控录像.mp4 --every 0.5 --conf 0.4 --out 结果目录 --reel
```

| 参数 | 说明 | 默认值 |
|---|---|---|
| `--every N` | 每隔 N 秒抽一帧检测。N 越小越准、越慢 | 1.0 |
| `--conf X` | 置信度阈值。调低减少漏检，调高减少误检 | 0.5 |
| `--gap N` | 两次检测间隔超过 N 秒则算作两个片段 | 3.0 |
| `--out 目录` | 输出目录（默认在视频旁边建 `<文件名>_找人结果`） | — |
| `--reel` | 额外剪出“只有人”的集锦视频（需安装 ffmpeg） | 关闭 |

输出目录里有：

- `report.html` —— 可点击跳转的报告（缩略图 + 时间点）
- `segments.json` —— 有人片段的时间数据（可供二次开发）
- `thumb_*.jpg` —— 每个片段起始帧的缩略图（已标出检测到的人）

## 实用说明

- **首次运行会自动下载 YOLO 模型**（yolov8n.pt，约 6MB），之后离线也能用。
- **速度参考**：默认每秒抽 1 帧，普通 CPU 约每秒处理 5~15 帧；
  1 小时录像（按每秒抽 1 帧 = 3600 次检测）大约需要十几到几十分钟。
  赶时间可用 `--every 2` 翻倍提速，精度略降。
- **只适用于录好的视频文件**（mp4 / avi / webm 等），不支持实时监控流。
- 画面里的人太小、太暗或被严重遮挡时可能漏检；可尝试调低 `--conf`。
- `--reel` 需要系统装有 ffmpeg；没装会自动跳过，不影响报告生成。

## 原理

OpenCV 按固定间隔抽帧 → YOLOv8n 检测画面中的人（COCO 类别 person）
→ 把连续的“有人时刻”合并成片段 → 生成带缩略图的跳转报告。
